# Improve Mode Checklist

Run this checklist after the skill improves an existing README. Every item is yes/no.

## Gap Analysis

- [ ] Skill presented a gap report before making changes
- [ ] Gap report correctly identified missing sections
- [ ] Gap report correctly identified weak sections
- [ ] Gap report did not flag strong sections as needing work

## Preservation

- [ ] Existing title is preserved exactly
- [ ] Strong existing content is kept verbatim (not rewritten)
- [ ] Adequate existing content is kept (minor tweaks at most)
- [ ] Author's tone and vocabulary are matched in new content
- [ ] Existing section order is respected (new sections added in logical positions)

## Enhancement

- [ ] Missing sections are filled with relevant content
- [ ] Weak sections are strengthened with specific, accurate detail
- [ ] Added content does not clash tonally with preserved content
- [ ] No existing information was lost or contradicted

## Quality

- [ ] The improved README reads as a cohesive document, not a patchwork
- [ ] New content follows the same formatting conventions as existing content
- [ ] No placeholder text was introduced
- [ ] Code blocks in new content have language hints
- [ ] Commands in new content are correct for the project's toolchain

## Overall

- [ ] The README is better than before (not just different)
- [ ] A reader could not easily tell which parts are original vs. added
- [ ] Nothing factually wrong was introduced
